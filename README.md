# Switch Generator

Автор: Хохлов Денис Андреевич, группа M3115

Плагин для **VS Code**, который создаёт `switch` с нужными `case`. Пользователь вводит значения, плагин сам пишет весь `switch` с `break` в каждой ветке и `default` в конце.

## Возможности

- спрашивает значения через запятую или пробел: `1, 2, 3` или `RED GREEN`;
- понимает диапазоны: `1-5` превращается в `case 1`, `case 2`, ... `case 5`;
- одиночная буква становится символом: `a` превращается в `case 'a':`;
- убирает повторы (два одинаковых `case` — ошибка компиляции);
- в скобки пишет выделенный текст или слово под курсором (если ничего нет, пишет `x`);
- вставляет код под текущей строкой с таким же отступом (на пустой строке — вместо неё).

## Как установить

Плагин написан на обычном JavaScript, компилировать ничего не нужно.

**Вариант 1. Файлом .vsix** (проще всего): в VS Code открыть вкладку расширений, нажать `...` → **Install from VSIX...** и выбрать файл `switch-generator-1.0.0.vsix`. Или в терминале:

```bash
code --install-extension switch-generator-1.0.0.vsix
```

**Вариант 2. Папкой:** скопировать эту папку в `~/.vscode/extensions/switch-generator-1.0.0` и перезапустить VS Code.

После установки в любом файле: поставить курсор на переменную и нажать `Ctrl+Alt+E` (на Mac `Cmd+Alt+E`)
или выбрать в палитре команд (`Ctrl+Shift+P`) «Создать switch-case». Появится окошко, куда вводятся значения.

## Документация

Весь код лежит в `extension.js`, у каждой функции есть комментарий:

- `activate` — регистрирует команду;
- `generateSwitch` — главная функция: спрашивает значения, собирает код и вставляет его в редактор;
- `getExpression` — берёт выделенный текст или слово под курсором;
- `parseCases` — режет введённый текст на части и через `Set` убирает повторы;
- `toLabels` — превращает одну часть в case: раскрывает диапазон, оборачивает букву в кавычки;
- `buildSwitch` — собирает текст `switch`.
