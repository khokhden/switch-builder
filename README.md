# Switch Generator

**Автор:** Хохлов Денис Андреевич, группа М3115

**IDE:** Visual Studio Code

Плагин для VS Code, который создаёт конструкцию `switch` с нужными `case`. Пользователь вводит значения, а плагин сам пишет весь `switch`: `case` для каждого значения, `break` в каждой ветке и `default` в конце.

## Возможности

- команда «Создать switch-case» в палитре команд (`Ctrl+Shift+P`) и сочетание клавиш `Ctrl+Alt+E` (на Mac `Cmd+Alt+E`);
- окошко для ввода значений через запятую или пробел: `1, 2, 3` или `RED GREEN`;
- диапазоны чисел: `1-5` превращается в `case 1`, `case 2`, ... `case 5` (не больше 101 значения за раз);
- одиночная буква становится символом: `a` превращается в `case 'a':`;
- повторы убираются: два одинаковых `case` — ошибка компиляции;
- в скобки `switch` подставляется выделенный текст или слово под курсором (если ничего нет — `x`);
- код вставляется под текущей строкой с тем же отступом, а на пустой строке — вместо неё;
- отступы берутся из настроек редактора (пробелы или табуляция);
- если нажать Esc, ничего не происходит; если ввод не получилось разобрать, выводится сообщение об ошибке.

## Пример

Курсор стоит на переменной `n`, в окошко введено `1-3, a, b, a`:

```cpp
switch (n) {
    case 1:
        break;
    case 2:
        break;
    case 3:
        break;
    case 'a':
        break;
    case 'b':
        break;
    default:
        break;
}
```

## Установка

Плагин написан на JavaScript, компилировать ничего не нужно.

1. Собрать установочный файл: `npx @vscode/vsce package` (получится `switch-generator-1.0.0.vsix`).
2. В VS Code открыть вкладку расширений, нажать `...` → **Install from VSIX...** и выбрать файл. Или в терминале: `code --install-extension switch-generator-1.0.0.vsix`.

## Файлы проекта

- `extension.js` — весь код плагина;
- `package.json` — манифест: название, команда, сочетание клавиш;
- `docs/` — документация: HTML-страницы, сгенерированные утилитой JSDoc из комментариев в коде (`docs/index.html`), и `docs/README.md` с описанием функций.

Документация генерируется командой:

```bash
npx jsdoc extension.js -d docs
```
